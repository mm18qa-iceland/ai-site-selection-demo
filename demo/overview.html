1模型架构：双层漏斗，三层串行

工具定位是"过滤器与排序器，不是决策器"——排除明显不合格的、给合格的排序，最终签字仍由人。
第一层漏斗 · 城市准入（K₁ × K₂ 乘积闸口）
回答"这座城值不值得进"：≥1.10 准入｜0.85–1.10 谨慎（点位线提至 80 分、首批 ≤2 家试点）｜<0.85 暂缓
第二层漏斗 · 点位评估（闸口 → 评分 → 财务，各自独立、串行生效）
闸口层 · 能不能做9 项量特征（OSM 客观抓取，半径写死）→ 决策树定店型 → 五项红线一票否决
评分层 · 过不过、排第几百分位相对排名对照在营门店基线，四大板块 100 分制，短板自动降档
财务层 · 赚不赚钱、合不合规简版测算（最小盈利假设）＋行业基准校验＋合规两道前置过滤

3K₂ 钟形分段函数：为什么甜蜜点是 5–12 家/万人

密度是"市场教育完成"的结果变量：太少＝未教育，太多＝红海，中间才是"需求已验证且未饱和"的进入窗口。绿色区间为甜蜜点（管理页可调）。

5验证结果：与行业结论对照

城市排序一致
广州 K₁×K₂≈1.66、深圳≈1.70、武汉≈1.34，华中/华南/华东一二线全部过准入线，非目标城市落在谨慎/暂缓区间——与"三大区域一二线城市确定性最高"的行业结论完全对应。
三档机制正常

6已知局限（如实说明）与后续计划

局限
  • 百分位基线为示例值，首批 ≥30 家实测回灌前只具排序意义
  • OSM 对中国商业 POI 覆盖偏弱，商业类指标可能低估，竞品类以高德/踏勘补录
  • 未配置高德 Key 时 POI 与地址解析走演示/降级通道
  • 财务测算为签约前过滤口径，非预算书
  • 教育度标签为规则标记（示范区身份＋城市排名＋素养水平），非计量模型
后续计划
  • 接入高德 API 替换演示通道（地址解析通道已预留，配 Key 即生效）
  • 首批 ≥30 家标准店量特征回灌，替换百分位基线
  • 每新增 20 家门店，以实际客单价残差回归校准 K₁/K₂ 一次
  • 按各市最新统计公报更新收入与医疗保健占比
  • 教育度标签随素养年度发布与艾灸馆城市排名滚动复核
